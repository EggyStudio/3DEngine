# Wick

`games/Wick` is a puzzle in a dark house, its one light at the start a lamp the player carries,
which casts shadows, so its light reaches round a corner or through a doorway only as light that
bounces through the scene's distance field, on polished floors that reflect it and hide their pits
until some light falls on them, each wick lit a light of its own.

It is built outside the solution from the package `build/pack.sh` makes, as a game of your own would
be, as [BUILDING.md](../../.github/BUILDING.md) says.
