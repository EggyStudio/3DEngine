# Jelly

`games/Jelly` is a runner, a blob of jelly on a road of three lanes that squashes and stretches by
its model's morph targets, each run recorded as automation events and watched again, the best kept
in a file, since its course comes from a seed and each step of it is a sixtieth of a second, so a
run's input played again makes the same run.

It is built outside the solution from the package `build/pack.sh` makes, as a game of your own would
be, as [BUILDING.md](../../.github/BUILDING.md) says.
