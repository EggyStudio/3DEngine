# Pusher

`games/Pusher` is a small game. It has a level from a scene file, an animated player pushing crates
into a goal with physics and contacts, a light with a shadow, a sky, a sound, text, an ImGui panel,
and a menu, play and pause.

It is built outside the solution from the package `build/pack.sh` makes, as a game of your own would
be, as [BUILDING.md](../../.github/BUILDING.md) says.
