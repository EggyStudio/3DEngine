# Hopper

`games/Hopper` is the 2D counterpart of `games/Pusher`, a platformer with a sprite sheet, a tile
atlas, a following 2D camera, coins, music, a loaded font, a scaled pixel view, a gamepad and a
saved high score.

It is built outside the solution from the package `build/pack.sh` makes, as a game of your own would
be, as [BUILDING.md](../../.github/BUILDING.md) says.
