# Hello

`dotnet run` opens the game. `Program.cs` is the game and its behaviors, `resources/` holds what it loads, and `source/behaviors/` holds scripts the running game compiles again when they are saved.
The engine's calls are listed in [CHEATSHEET.md](https://github.com/EggyStudio/3DEngine/blob/main/CHEATSHEET.md), and its guide to behaviors is in [docs](https://github.com/EggyStudio/3DEngine/tree/main/docs).
